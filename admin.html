Přihlášení do adminu

Pro správu produktů zadejte GitHub Personal Access Token.

Jak získat token:
  1. Jděte na github.com/settings/tokens/new
  2. Název: Korálky Admin
  3. Zaškrtněte repo (celé)
  4. Klikněte Generate token
  5. Zkopírujte token a vložte sem
Token se uloží jen do tohoto prohlížeče.
